# Canonical Models

Shared provider-independent domain contracts.

Initial model families:

- Provider / Connector / Capability / Route
- Tenant / Merchant / Site
- Service / Product
- Customer
- Device
- Transaction / TransactionEvent
- Payment
- Vend / Fulfilment
- Refund
- Settlement
- ReconciliationException
- SupportCase
- WebhookEvent
- ProviderHealth
- Alert / Incident
- ApprovalRequest
- AuditEvent

Canonical models preserve provider-native identifiers/status/error metadata where operationally useful.
