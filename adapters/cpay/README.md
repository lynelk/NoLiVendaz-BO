# CPay Adapter

Integration boundary for `lynelk/CPay`, including ChargeNow/vending capabilities and CPay financial services where exposed.

Target capabilities include, subject to actual CPay API contracts:

- payment initiation and query;
- vending/ChargeNow initiation and query;
- merchant and device mappings;
- refund operations;
- settlement data;
- reconciliation data;
- billing references;
- webhook verification and normalization.

CPay is an important integration spine, not a mandatory path for every future vending provider.
